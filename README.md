# Show, Don't Prompt
**Record what you're seeing. Tell AI what you want.**
Open-source local-first desktop visual-context capture for AI/coding agents.
Shortcut -> select region/window/screen -> record + optional narration -> stop -> instruction -> provider-neutral Capture Bundle -> chosen AI/agent.

Stack: Tauri 2, Rust, Vue 3, TypeScript, Vite, Tailwind, Pinia, pnpm/Turborepo, SQLite.
Start with `AGENTS.md`. `docs/` is the canonical second brain and can also be opened as an Obsidian vault.
