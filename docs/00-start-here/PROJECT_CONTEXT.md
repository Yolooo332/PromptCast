# Project Context
Updated 2026-10-07.
Show, Don't Prompt makes demonstration a first-class AI prompt format.

Flow: shortcut -> select region/window/screen -> record while optionally speaking -> stop -> short instruction -> send structured context to an AI provider or coding agent.

A Capture Bundle can contain recording, microphone audio, transcript, keyframes, timestamps, safe optional interaction/window metadata, user instruction, and explicitly granted project context.

Primary users: developers/coding-agent users, frontend/design engineers, QA/support.
Not this: continuous surveillance, always-on screen memory, Loom clone, single-provider wrapper, or billing/API bypass.
North star: **Record -> speak/show -> stop -> send -> useful answer/action.**
