# Product Vision
AI increasingly understands visual context, but users still translate dynamic visual problems into text. Demonstration should be a first-class prompt format.

Principles: instant, deliberate, portable, model-agnostic, agent-ready, private by architecture, beautiful.

GitHub strategy: instantly understandable demo, real pain point, polished UX, open Capture Bundle, extensible adapters, excellent docs, contributor-friendly architecture, frequent releases.
