# Product Specification
Core flows:
- Record: shortcut -> select -> optional mic -> minimal HUD -> stop/cancel -> process.
- Screenshot: same context pipeline.
- Prompt: instruction/recipe -> destination/model -> send -> result.
- Providers: supported APIs/local endpoints.
- Agent handoff: structured coding task.
- History: local captures, inspect sent context, retry, delete.

v0.1: macOS+Windows, region recording, mic, persistence, Capture Bundle, keyframes, transcription abstraction, Gemini adapter, generic multimodal adapter, result UI, secure credentials, history, one agent handoff.
Not v0.1: cloud teams/accounts/billing, continuous recording, mobile, marketplace.
